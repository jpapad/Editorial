# SQL για το Supabase

Όλα τα SQL που χρειάζεται η εφαρμογή, αριθμημένα με τη σειρά που τρέχουν.
Τρέχουν στο **Supabase → SQL Editor** (επικόλληση → Run).

Όλα είναι **ασφαλή να ξανατρέξουν**. Αν δεν θυμάσαι τι έχεις τρέξει, απλώς τρέξε ξανά το `00_ALL.sql`.

| Αρχείο | Τι κάνει |
|---|---|
| `00_ALL.sql` | **Όλα τα παρακάτω μαζί**, με τη σωστή σειρά. Το πιο απλό: τρέξε μόνο αυτό. |
| `00_books.sql` | Ο βασικός πίνακας βιβλίων. Στη δική σου βάση υπάρχει ήδη και δεν αλλάζει τίποτα· σε **καινούργιο** project Supabase πρέπει να τρέξει πρώτο |
| `01_admin_role.sql` | Ρόλος supervisor/admin, σελίδα `/studio/admin` |
| `02_page_comments.sql` | Σχόλια supervisor ανά σελίδα |
| `03_book_print_settings.sql` | Bleed, χαρτί, εξώφυλλο (KDP) |
| `04_book_shares.sql` | Σύνδεσμοι κοινοποίησης για παιδιά (`/share/…`) |
| `05_usage_and_templates.sql` | Όρια AI ανά μήνα, στατιστικά admin, πρότυπα κοινότητας |
| `06_user_library.sql` | «Τα stamps μου» και ιστορικό εκδόσεων στον λογαριασμό (όχι μόνο στη συσκευή) |
| `07_image_storage.sql` | Bucket Storage `book-images`: οι εικόνες των βιβλίων ανεβαίνουν εκεί αντί να αποθηκεύονται μέσα στο βιβλίο |
| `08_user_media.sql` | Βιβλιοθήκη πολυμέσων: κατάλογος με όσες εικόνες ανέβασε ή δημιούργησε ο χρήστης |
| `09_billing.sql` | Πλάνα (Free/Pro/Studio) και αγορασμένα credits AI μέσω Stripe. Ξαναορίζει τα όρια AI του `05` (μετά το `05`) |
| `10_kid_groups.sql` | Τάξεις & οικογένειες: τα παιδιά μπαίνουν στο `/kids` με κωδικό και δύο εικόνες, ζωγραφίζουν τα βιβλία της ομάδας και τα έργα τους φυλάγονται στον λογαριασμό |
| `11_book_members.sql` | Συνεργάτες σε βιβλίο: σύνδεσμοι πρόσκλησης για συντάκτες/θεατές, «Κοινόχρηστα μαζί μου». Ο ιδιοκτήτης ενός βιβλίου δεν αλλάζει ποτέ. Ξαναορίζει το `can_review_book` του `02` (μετά το `02`) |
| `12_app_errors.sql` | Καταγραφή σφαλμάτων (server και browser), ορατή στους supervisors στο `/studio/admin` |

## Αν τα τρέχεις ένα-ένα

Με τη σειρά των αριθμών, από το `00_books.sql`. Αν ξανατρέξεις το `01`, τρέξε μετά ξανά και το `05`
(ξαναορίζει τη λίστα χρηστών του admin με τις στήλες AI). Αν ξανατρέξεις το `05`, τρέξε μετά ξανά και το `09`
(ξαναορίζει τα όρια AI ώστε να μετράνε τα πλάνα και τα αγορασμένα credits).

## Πρώτος supervisor

Μετά το `01`, φτιάξε τον λογαριασμό (Authentication → Users) και τρέξε:

```sql
insert into public.app_admins (user_id)
select id from auth.users where email = 'to-email-sou@example.com'
on conflict do nothing;
```

Από εκεί και πέρα προάγεις άλλους από τη σελίδα Admin.

## Για νέα αλλαγή στη βάση

Νέο αρχείο με τον επόμενο αριθμό (`06_…sql`), ασφαλές να ξανατρέξει, και μετά `npm run sql:all`.
